flowscope

Run /explain in a Python project. Get a one-page explanation of how it works, made from your tests.

It runs your tests with a tracer, sees which parts of the code each one uses and where the time goes, and writes one HTML page you can open offline, mail or print to PDF.

Example pages

Made from the five tests in a small shop project. Open them in your browser.

For stakeholdersWhat the system does, where it is slow, what no test covers. For learning the systemArchitecture, request flow, where state lives, a reading order. For an interviewComponents, design decisions, bottlenecks, questions to expect.

Install

claude plugin marketplace add vishalbanwari26/flowscope
claude plugin install flowscope@flowscope

Then run /explain, /explain learn or /explain interview inside a Python project with pytest tests.
